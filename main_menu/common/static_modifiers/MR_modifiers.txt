# --- The Kurultai Defied (mr_partition.100 option B, 25 years) ---
# The price of keeping the map whole. Refusing the assembly costs
# nothing in territory and buys nothing in cohesion.
#
# The cost is deliberately NOT rebellion. This mod's modifiers push
# monthly_rebel_growth DOWN almost everywhere on purpose: an AI Khaghan
# cannot manage a revolt, and a railroad that collapses into unrest it
# cannot fight stops being a railroad. Giving the AI a 40%-chance option
# that raises rebel growth would have undone that everywhere at once.
# So defiance is paid in legitimacy and horde unity — currencies the AI
# survives — and in the cabinet and the control the ulus khans were
# enforcing.
#
# REWRITTEN 2026-07-30: this used to say the cost also landed on the
# situation's own gauge, through a mr_partition_concessions term that
# option B subtracted from. That whole currency is gone. It let the
# Khaghan BUY the cohesion score back while the map stayed permanently
# partitioned — measured climbing 65 → 80 → 100 in a live run — and a
# gauge that can be paid to disagree with the map is not a gauge. The
# schedule was always the thing actually taking the empire apart.
# AUDIT 2026-07-30: the block below used to carry
# `monthly_rebel_growth = 0.005`, i.e. it did the one thing the comment
# above it forbids, on an option the AI takes 40% of the time, for 25
# years. Two comments in this mod contradicted each other over it - the
# option's own comment at MR_partition_events.txt:331 said the realm
# "pays for the refusal in unrest". The rule wins; the line is gone.
#
# WHAT REPLACED IT, and why not the obvious thing. subject_loyalty is a
# DEAD lever on this claimant: six MR modifiers already push it +25,
# +50 or +100, several of them permanent phase rewards, so a -15 moves
# nothing a player would notice. The substitutes are levers with no
# counterweight anywhere in the mod - the cabinet the ulus khans staff,
# and the control they were enforcing - plus a deeper cut to the
# situation's OWN gauge, which is where the comment above always said
# the real cost belonged.

# =================================================================
# THE GREAT PARTITION - THE KHAGHAN'S DECLINE (three tiers)
# =================================================================
# The strain of holding an empire that has stopped answering. Granted
# by the situation inside the three threshold beats it already fires
# (85 / 55 / 40), each tier replacing the one before it, and REMOVED
# in on_ending: this is a pressure gauge, not a phase reward, and
# unlike MR_the_ulus_endures it must not outlive the situation.
#
# WHY THREE LITERAL BLOCKS AND NOT ONE SCALED MODIFIER. The engine
# does take a `size` multiplier on add_country_modifier, and a single
# block scaled by cohesion would be prettier. It was rejected on
# evidence: "size multiplies every value in the modifier" is inferred,
# never stated by effects.log, and a wrong inference there silently
# corrupts every tag at once. The guarded-swap variants need either a
# numeric `var:X = var:Y` comparison (ZERO vanilla attestations - all
# three vanilla uses compare COUNTRIES) or `set_to_largest_and_extend`
# with an infinite duration (attested only with years = 50). Three
# literal blocks are individually citable and individually readable in
# the tooltip, which is worth more here than elegance.
#
# NOT ONE UNREST TAG IN ANY OF THE THREE. No monthly_rebel_growth, no
# global_separatism, no local_unrest, no pop_join_rebel_threshold, and
# deliberately NOT `has_complacency_effects = yes` either - that
# switch routes into pop_join_rebel_threshold = 0.1 through
# auto_modifiers/country.txt:456, which quietly imports the whole
# vanilla decline family the house rule exists to keep out.
#
# TWO LEVERS DELIBERATELY ABSENT, because they are DEAD on this
# claimant: subject_loyalty (MR_unified_mongol_banner already gives a
# permanent +25 and MR_great_khan another +100, so subjects sit pinned
# at the cap and a -25 moves nothing) and aggressiveness_modifier
# (netted against +1 from MR_great_khan and +1 from
# MR_imperial_historical_modifier). ai_months_between_wars and
# carefulness_modifier do that job with no counterweight.
#
# Vanilla citations below: country.txt = main_menu/common/static_modifiers/country.txt,
# hcw = in_game/common/disasters/horde_civil_war.txt,
# coup = in_game/common/disasters/coup_attempt.txt,
# succ = in_game/common/disasters/succession_crisis.txt,
# aip = in_game/common/ai_personalities/00_ai_personalities.txt.
