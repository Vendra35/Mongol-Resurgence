# --- The Chinggisid Blitz (character modifier, FIRST KHAN ONLY) ---
# auto_conquer_at_war used to sit in MR_great_khan, which all three
# generations receive. It turns every completed occupation into
# ownership on the spot, with no peace deal — so it bypasses the
# wargoals' allowed_locations entirely, which is the system every phase
# goal rests on and the one verify_mod.py has a coverage check for. The
# visible symptom was Phase 2 bordergore: peace deals produce contiguous,
# goal-scoped gains, occupation-conquest produces whatever the army
# walked through.
# Split out so only Batu (mr_dominance.104, Phase 1) carries it. Phase 1
# IS the blitz — unify the steppe, one banner, fast. Phases 2 and 3 are
# meant to be deliberate, fought through the railroad's war events and
# their wargoals, and Phase 3 is Pax Mongolica besides. Vanilla agrees on
# the shape: timmy_wants_to_play gives it to Timur the man, not to a
# dynasty (character.txt:1813).
# To extend it to the second khan later, add one add_character_modifier
# call to mr_dominance.120 — nothing else needs to change.
MR_chinggisid_blitz = {
	game_data = {
		category = character
	}
	auto_conquer_at_war = yes
}

# --- The Kurultai Defied (mr_partition.100 option B, 25 years) ---
# The price of keeping the map whole. Refusing the assembly costs
# nothing in territory and buys nothing in cohesion.
#
# The cost is deliberately NOT rebellion. This mod's modifiers push
# monthly_rebel_growth DOWN almost everywhere on purpose: an AI Khaghan
# cannot manage a revolt, and a railroad that collapses into unrest it
# cannot fight stops being a railroad. Giving the AI a 40%-chance option
# that raises rebel growth would have undone that everywhere at once.
# So defiance is paid in legitimacy and horde unity — currencies the AI
# survives — and above all in the situation's OWN gauge: option B also
# subtracts from mr_partition_concessions, so cohesion falls faster and
# more uluses break away at the end. Same pressure, expressed where the
# situation can actually resolve it.
MR_kurultai_defied = {
	game_data = {
		category = country
	}
	monthly_rebel_growth = 0.005
	monthly_legitimacy = -0.5
	monthly_horde_unity = -0.5
}
