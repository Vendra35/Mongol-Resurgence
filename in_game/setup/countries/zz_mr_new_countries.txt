# The Manchus, who become the Qing. MEASURED IN GAME 2026-07-31:
# **QNG IS NOT A TAG.** Vanilla's Qing is the MCH tag renamed —
# flavor_MCH.txt:1024-1030 (flavor_mch.17, "Proclamation of the
# Qing") forms CHI_f on an MCH country and then writes QNG as its
# NAME, adjective and colour. `QNG` is a loc key (country_names
# :3034) and `map_QNG` a named colour; neither needs a registration.
# So the block that was here, registering QNG as a tag of its own,
# was a detour: it spawned, immediately satisfied MCH_f's potential
# (`culture ?= { has_culture_group = culture_group:jurchen_group }`,
# 00_formable_countries.txt:3428) because it held all of Manchuria,
# and the AI formed Later Jin — arriving at MCH by luck. Observed in
# the author's own campaign: country key 2342 (this block), Tag MCH,
# Historical Tag CHI.
#
# MCH itself has NO identity block anywhere in vanilla — zero hits
# for "MCH" across all 46 files of in_game/setup/countries/ and all
# of main_menu/setup/. Its only registration is MCH_f. So
# `change_location_owner = c:MCH` cannot instantiate it, which is
# exactly what the 1670 probe measured: mr_return_manchuria ran and
# nothing appeared. This block is what closes that.
#
# Registering MCH also buys what QNG could never have: the real
# Manchu coat of arms (pre_scripted_countries.txt:23903), map_MCH
# (02_map.txt:2333), the six country_MCH.txt advances — which are
# gated `has_or_had_tag = MCH` and so SURVIVE a later re-tag — and
# the nineteen-event flavor_MCH chain.
#
# culture: jurchen_culture — the Manchus are the Jurchens renamed,
# and it is the only culture in that family vanilla defines. It is
# also what makes vanilla's own Manchu content recognise this tag.
# religion: tungusic_shamanism, which vanilla gives to SIB, the
# Sibe, their nearest surviving relatives (east_asia.txt).
# NOTE both are RELEASE-time fields and a handover is not a release:
# the same campaign showed this country arrive TENGRI, not Tungusic
# Shamanist. The partition effect writes religion by hand.
