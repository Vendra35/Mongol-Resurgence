namespace = mr_distant

# =================================================================
# NEWS FROM THE EAST - the world beyond the conquest
# =================================================================
# The Great Partition always had three audiences: the Khaghan, his
# neighbours, and distant spectators. The three phases that BUILD the
# empire had only two - the claimant, and whoever happened to hold the
# ground a phase was currently taking. Phase 1's every outward event is
# gated on mongolian_group + steppe_horde, so nobody outside the steppe
# hears it at all; Phase 2 speaks only to holders of its six goal
# regions; Phase 3 adds Persia, the Pontic, Russia, China and Anatolia.
#
# So a player in western Europe, in Egypt or in India could watch a
# Mongol empire grow from Korea to the Levant across three centuries
# and never once be told a thing was happening. This file is that
# missing thread.
#
# THREE BEATS, AND THEY ESCALATE, because that is how the news actually
# travelled: rumour, then an envoy, then an army on the horizon.
#   .1  Phase 2 opens   - traders and refugees, a rumour worth hearing
#   .2  MGE proclaimed  - an embassy arrives and asks for submission
#   .3  Phase 3 opens   - it is no longer news, it is a border
#
# AUDIENCE is mr_distant_observer (scripted_triggers): the outer ring
# only - not the Khaghan, not his neighbours, and only the parts of the
# world that historically heard of the Mongols. Sub-Saharan Africa, the
# Americas and Oceania are deliberately excluded; no word reached them
# and none should. Neighbours are excluded because they already get
# targeted events at these same moments, and nobody should hear the
# same news twice.
#
# NOTHING HERE GRANTS A MODIFIER. These are news, not rewards. The rule
# this mod already follows - flavour events grant their OWN modifier and
# never a phase reward - is satisfied most simply by granting nothing at
# all. A distant power learning that a Mongol empire exists has not
# earned anything; it has been told something.
# =================================================================

# --- 1. RUMOUR (Phase 2 opens, ~1420) ----------------------------
# The caravans come through thinner and later than they used to, and
# the men leading them have a story. This is the stage at which Europe
# first heard of Chinggis - garbled, third-hand, and mixed up with
# Prester John.
mr_distant.1 = {
	type = country_event
	category = situation_event
	title = mr_distant.1.title
	desc = mr_distant.1.desc
	historical_info = mr_distant.1.historical_info
	outcome = neutral
	fire_only_once = yes
	illustration_tags = {
		10 = exterior
		10 = regular
	}
	option = {
		name = mr_distant.1.a
		ai_chance = {
			factor = 100
		}
	}
}

# --- 2. THE EMBASSY (MGE is proclaimed, ~1550) -------------------
# The Mongol envoys really did arrive with this message and really did
# phrase it this way: submit, and you will be spared; refuse, and God
# knows what will happen, we do not. Innocent IV received it in 1246 in
# reply to his own letter, and it is the reason the option below is
# refusal without consequence - the mod does not punish a distant power
# for saying no to a demand it has no way to answer.
mr_distant.2 = {
	type = country_event
	category = situation_event
	title = mr_distant.2.title
	desc = mr_distant.2.desc
	historical_info = mr_distant.2.historical_info
	outcome = neutral
	fire_only_once = yes
	major = yes
	illustration_tags = {
		10 = interior
		10 = regular
	}
	# TWO ANSWERS, AND THIS IS THE ONLY PLACE IN THE MOD WHERE A COUNTRY
	# OUTSIDE THE CONQUEST DECIDES ANYTHING. Every other distant event is
	# a notification; a notification the player cannot answer is a thing
	# they learn to click through. The envoys really did put this question
	# to everyone within reach and the answers really did differ - the Rus
	# princes, the Seljuks of Rum, Armenia and Georgia submitted; the
	# Mamluks and the Hungarians refused - so both answers are written as
	# real ones and neither is correct.
	option = {
		name = mr_distant.2.a
		# Submit. Quiet, bought with pride.
		add_prestige = prestige_mild_penalty
		add_country_modifier = {
			modifier = MR_tribute_to_the_khan
			years = 25
			mode = add
		}
		ai_chance = {
			factor = 50
			# The weak submitted and the strong did not, which is most of
			# what decided it. An AI already at war has even less room.
			modifier = {
				factor = 2
				at_war = yes
			}
		}
	}
	option = {
		name = mr_distant.2.b
		# THE HISTORICAL ANSWER, for THIS audience. historical_option is a
		# separate feature from historical_info above - that one is the
		# content of the info box, this one marks which choice history
		# actually made. The two are independent: 398 vanilla events declare
		# historical_info with no historical_option anywhere in them.
		#
		# Refusal is the historical answer here because of WHO receives this
		# event. The powers that submitted - the Rus principalities, the
		# Seljuks of Rum, Georgia, Armenia - were the ones with a Mongol army
		# in front of them, and they are the neighbour ring, which this event
		# deliberately excludes. The outer ring is western Europe, Egypt and
		# India: Europe was never made to answer, the Mamluks refused and won
		# at Ain Jalut, and Delhi fought the raids off for a century.
		historical_option = yes
		# Refuse. Pride, bought with risk.
		add_prestige = prestige_mild_bonus
		add_country_modifier = {
			modifier = MR_defied_the_khan
			years = 25
			mode = add
		}
		ai_chance = {
			factor = 50
			modifier = {
				factor = 2
				at_war = no
			}
		}
	}
}

# =================================================================
# THE NAMED BLOWS - four moments the world recorded by name
# =================================================================
# The three beats above are the shape of the news: rumour, envoy,
# border. These four are the CONTENT - the specific events that made
# the thirteenth century remember the Mongols, fired when this
# campaign reaches the same places. They hang off the claimant
# actually holding the ground, not off a timer, so a campaign that
# never takes Baghdad never hears about Baghdad.
#
# And the last of them is deliberately not dread. The Mongol century
# was not only terror: it reopened the road from the Mediterranean to
# China under one jurisdiction for the first and only time, and that
# is how Rubruck, Polo and Ibn Battuta got where they were going. A
# mod that only ever frightens the distant player is telling half the
# history - and the fear lands harder when it is not the only note.
# =================================================================
