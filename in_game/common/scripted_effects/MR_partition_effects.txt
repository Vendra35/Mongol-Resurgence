# =================================================================
# THE GREAT PARTITION - HISTORY RESUMES, ONE THEATRE AT A TIME
# =================================================================
# One effect per theatre the restored empire gives back, written
# ONCE and called from TWO places, the same way mr_p2_*_cleared is
# one trigger read by both an end condition and a panel score:
#
#   MR_great_partition.txt  on_monthly  - on that theatre's schedule
#   MR_great_partition.txt  on_ending   - the final sweep, when the
#                                         empire is over and whatever
#                                         is left goes home at once
#
# Before this file the handover lived inline in on_ending in six
# copies of the same eleven lines, each carrying the same eleven-line
# comment. Adding the settled world would have made that fourteen
# copies in two places. Now a theatre's boundary, its heir and its
# guard flag are named in exactly one place.
#
# EACH EFFECT IS IDEMPOTENT. The global flag is checked inside, not
# by the caller, so on_ending can simply call all sixteen and the
# ones that already fired do nothing. A theatre also never fires
# twice, which matters: without the flag a reconquest would be
# snapped back out of the Khaghan's hands every month.
#
# WHO IT TAKES FROM is mr_partition_takeable (scripted_triggers):
# claimant realm, and never a HUMAN vassal's ground. See the D6
# ruling there.
#
# WHY THESE HEIRS. Every one is the power that actually held that
# ground around 1650-1700 — not the 1337 owner, and not a 1337
# khanate. This situation exists to close the alternate timeline
# back onto the real map, so a Golden Horde reappearing in 1650
# would be a second piece of alternate history, and a Mongol empire
# that "collapses" while still running from Shiraz to Canton is not
# a collapse at all. The dates in each comment are the real ones.
#
# change_location_owner brings a defined-but-landless tag onto the
# map by itself — no formable needed (vanilla revives SKE this way,
# flavor_swe_dan.txt:4-5) — CONFIRMED IN GAME 2026-07-30 when KAZ
# spawned. Every tag below either ships an identity block in vanilla
# or gets one in zz_mr_new_countries.txt, except RUS, which is only
# ever named behind country_exists.
#
# BUT A HANDOVER IS NOT A RELEASE, AND THE HEIR ARRIVES BLANK.
# `change_location_owner` moves ground and nothing else. It runs none
# of the engine's release path, so `religion_definition` and
# `culture_definition` in the identity block are never read — the
# Setup-modding wiki says outright that those two fields are "used to
# determine the culture and religion of this tag WHEN RELEASED".
# MEASURED IN GAME, twice: CRI arrived ORTHODOX although its vanilla
# block (steppes.txt:16-17) declares crimean/sunni, and the Manchu
# heir arrived TENGRI although its block declares tungusic_shamanism
# (Object Inspector, 1667 save: Tag MCH, religion "Tengrism", a
# generated ruler named Zongqian). The country takes its religion
# from the ground and the generated ruler, not from its own database
# entry.
#
# So every heir that is BORN here writes its own identity by hand,
# immediately after its seat is set:
#
#   create_character + set_new_ruler   a named founder instead of a
#                                      generated stranger — the same
#                                      shape this mod already uses for
#                                      the Great Khans (mr_dominance
#                                      .104), with `age` rather than
#                                      birth_date because the partition
#                                      has no fixed date. 487 of
#                                      vanilla's 1358 create_character
#                                      blocks do exactly that.
#   change_religion                    the country's own faith
#   change_religion_for_ruler_and_family   the ruler's, and his heirs'
#   change_culture                     the country's own culture
#
# That is vanilla's own order, from the four Delhi successors
# (fall_of_delhi.txt:181-193) and from Timur (flavor_tim.txt:549).
# Religion and culture values are each tag's OWN database entry, not
# an invention: crimean/sunni (steppes.txt:16), bashkir/sunni (:53),
# oirat_culture/tengri (east_asia.txt:3274), mongolian_culture/tengri
# (:2223), and for the three tags this mod registers itself, whatever
# zz_mr_new_countries.txt declares.
#
# THE SAME "DO NOT TOUCH" LIST APPLIES AS FOR set_capital: MOS, RUS,
# NOG, TUR, TIB and KOR are live 1337 countries with their own rulers
# and faiths. Nothing here is written for them.
# =================================================================
# --- 1. THE CRIMEAN KHANATE (1441) -------------------------------
# Haci Giray's ulus: furthest from Karakorum, and the Chinggisid
# state that outlived every other one, to 1783.
mr_return_crimea = {
	if = {
		limit = {
			NOT = {
				has_global_variable = mr_returned_crimea
			}
		}
		scripted_geography:MR_geo_crimean_seat = {
			every_location_in_scripted_geography = {
				limit = {
					mr_partition_takeable = yes
				}
				change_location_owner = c:CRI
				add_core = c:CRI
				change_integration_level = core
			}
		}
		# The Kuban and the Yedisan steppe come with the peninsula: the
		# Yedisan horde was a Crimean and Ottoman vassal by this period,
		# which the geography atom's own comment already says.
		scripted_geography:MR_geo_kuban_and_yedisan = {
			every_location_in_scripted_geography = {
				limit = {
					mr_partition_takeable = yes
				}
				change_location_owner = c:CRI
				add_core = c:CRI
				change_integration_level = core
			}
		}
		if = {
			limit = {
				country_exists = c:CRI
			}
			# Twenty-five years of grace. This is the clause that makes the
			# schedule mean anything: a fourteen-location Crimea next to a
			# superpower still carrying PERMANENT phase rewards is lunch, and
			# without it the map churns straight back to a blob.
			c:CRI = {
				# MEASURED: a tag brought onto the map by change_location_owner is
				# instantiated from its setup/countries identity block alone, and that block
				# authors NOTHING at runtime - no capital, no government, no culture, no
				# religion. CRI arrived ORTHODOX although its vanilla block declares sunni,
				# names rendered as "County of Kazakh", and vanilla propose_ruler.txt:29
				# errors forever on a country whose government_type link is unset. Vanilla
				# authors its own spawns the same way, at flavor_chi.txt:2545-2548.
				#
				# The capital is set AFTER the sweep, because a country cannot be seated in
				# ground it does not own yet, and every key here was verified to lie INSIDE
				# this heir grant - the obvious guesses do not: bakhchisaray does not exist,
				# ufa is in perm_area, turkestan is in transoxiana_area, gulja goes to KAZ.
				#
				# DO NOT add these calls for MOS, RUS, NOG, TUR, TIB or KOR. Those are live
				# 1337 countries with working capitals and governments; set_capital on them
				# MOVES a living capital.
				set_capital = location:qarasuvbazar

				# IDENTITY BY HAND — see the file header. crimean/sunni are
				# CRI's own database entry (steppes.txt:16-17); it arrived
				# ORTHODOX without this.
				#
				# THE RULER IS DATED TO WHEN THIS THEATRE ACTUALLY FIRES, NOT
				# to the khanate's real founding. Every theatre header carries
				# the true historical date because that is what fixes the
				# ORDER, but the alternate timeline delays the events
				# themselves: this one lands in 1652. Haci Giray founded the
				# ulus in 1441 and would be two centuries dead. The Crimean
				# khan of 1652 is Islam III Giray (1644-1654), aged 48. The
				# Girays were Chinggisids, so the house is still Borjigin.
				create_character = {
					estate = estate_type:nobles_estate
					first_name = Islam
					age = 48
					culture = culture:crimean
					religion = religion:sunni
					dynasty = dynasty:borjigin_dynasty
					adm = { 40 70 }
					dip = { 50 80 }
					mil = { 40 70 }
					create_in_limbo = yes
					save_scope_as = mr_crimea_khan
				}
				set_new_ruler = scope:mr_crimea_khan
				change_religion = religion:sunni
				change_religion_for_ruler_and_family = {
					country = c:CRI
					religion = religion:sunni
				}
				change_culture = culture:crimean
				add_country_modifier = {
					modifier = MR_ulus_of_its_own
					years = 25
					mode = add
				}
			}
		}
		# THE FLAG ONLY LANDS IF THE GROUND ACTUALLY WENT.
		#
		# MEASURED 1658, first live run: this family set its flag and moved
		# nothing. c:IRA had no country object, because a campaign in progress
		# cannot gain a tag added to setup/countries after the campaign was
		# created - the country database is minted once. The flag then sealed
		# the theatre for the rest of the campaign and Persia stayed Mongol
		# forever. A silent failure is survivable; one that marks itself done
		# is not.
		#
		# The test is the atom itself. If any claimant ground here is still
		# takeable the handover did not happen, so the effect retries next
		# month. If the atom never had any - the Khaghan did not own it - the
		# guard passes at once and the theatre is correctly recorded settled.
		if = {
			limit = {
				NOT = {
					OR = {
						scripted_geography:MR_geo_crimean_seat = {
							any_location_in_scripted_geography = {
								mr_partition_takeable = yes
							}
						}
						scripted_geography:MR_geo_kuban_and_yedisan = {
							any_location_in_scripted_geography = {
								mr_partition_takeable = yes
							}
						}
					}
				}
			}
			set_global_variable = mr_returned_crimea
		}
	}
}

# --- 12. THE QING TAKE CHINA (1644) ------------------------------
# Beijing falls to the Manchus in 1644 and the Ming are finished.
# Deliberately MCH — the Qing — and not MNG or CHI even when those live:
# this schedule is the 1650-1700 map, and in 1650 China is Qing.
mr_return_china = {
	if = {
		limit = {
			NOT = {
				has_global_variable = mr_returned_china
			}
		}
		# THE LAND FIRST, THE PROCLAMATION LAST (it now sits at the bottom
		# of this effect). MEASURED 2026-07-31: form_country writes the
		# formable's `tag` field onto this country WHEN THAT TAG IS FREE,
		# and leaves the tag alone when it is taken. Both halves were seen
		# in one campaign — the old QNG spawn formed MCH_f (MCH free) and
		# BECAME MCH; it then formed CHI_f, and because a rump CHI was
		# still alive it stayed MCH with Historical Tag CHI.
		# Vanilla guards the same hazard in four places: LAT_f
		# (00_formable_countries.txt:793/:801) and THE_f (:985/:995) both
		# carry NOT = { country_exists = c:X }; rise_of_the_ottomans.txt:355
		# checks it before forming RUM_f and addresses c:TUR at :379; and
		# red_turban_rebellions.txt:520 goes further, re-tagging the
		# incumbent CHI to YUA to FREE the tag first.
		#
		# Vanilla can afford to proclaim first because flavor_mch.17 is an
		# event option and NOTHING follows it — the country is never
		# addressed by tag again, so either outcome is an ending. Here five
		# things follow it, all naming c:MCH. In a campaign where CHI has
		# been annexed the form would succeed, MCH would become CHI, and
		# both sweeps, the seat, the rank and the grace modifier would
		# silently do nothing — forever, because the work-guard at the
		# bottom would correctly refuse to set the flag and the theatre
		# would retry every month achieving nothing.
		#
		# Land-first also makes CHI_f's own form_effect do more work:
		# rtr_recreate_middle_kingdom -> rtr_core_all_of_china_effect
		# (situation_effects.txt:175-193) only upgrades integration on
		# locations the country ALREADY owns.
		scripted_geography:MR_geo_north_china = {
			every_location_in_scripted_geography = {
				limit = {
					mr_partition_takeable = yes
				}
				change_location_owner = c:MCH
				add_core = c:MCH
				change_integration_level = core
			}
		}
		scripted_geography:MR_geo_song_china = {
			every_location_in_scripted_geography = {
				limit = {
					mr_partition_takeable = yes
				}
				change_location_owner = c:MCH
				add_core = c:MCH
				change_integration_level = core
			}
		}
		if = {
			limit = {
				country_exists = c:MCH
			}
			# Twenty-five years of grace. This is the clause that makes the
			# schedule mean anything: a fourteen-location Crimea next to a
			# superpower still carrying PERMANENT phase rewards is lunch, and
			# without it the map churns straight back to a blob.
			# Emperor of China from 1644. The ratchet lifts the Manchus from
			# the kingdom rank the Manchuria handover gave them. CHI_f's own
			# form_effect sets rank_empire too (00_formable_countries.txt
			# :3966) — but only if the proclamation below actually lands, and
			# it may not, so this call stays.
			c:MCH = {
				# MEASURED: a tag brought onto the map by change_location_owner is
				# instantiated from its setup/countries identity block alone, and that block
				# authors NOTHING at runtime - no capital, no government, no culture, no
				# religion. CRI arrived ORTHODOX although its vanilla block declares sunni,
				# names rendered as "County of Kazakh", and vanilla propose_ruler.txt:29
				# errors forever on a country whose government_type link is unset. Vanilla
				# authors its own spawns the same way, at flavor_chi.txt:2545-2548.
				#
				# The capital is set AFTER the sweep, because a country cannot be seated in
				# ground it does not own yet, and every key here was verified to lie INSIDE
				# this heir grant - the obvious guesses do not: bakhchisaray does not exist,
				# ufa is in perm_area, turkestan is in transoxiana_area, gulja goes to KAZ.
				#
				# DO NOT add these calls for MOS, RUS, NOG, TUR, TIB or KOR. Those are live
				# 1337 countries with working capitals and governments; set_capital on them
				# MOVES a living capital.
				#
				# A DURABLE HANDLE FOR THE PROCLAMATION BELOW. A saved scope is
				# the country OBJECT and survives a re-tag: nanbokuchou.txt
				# :134-153 keeps using scope:target_emperor straight through a
				# YMT_f form, and rise_of_the_ottomans.txt:364-365 writes a

				# reads it back afterwards. This is also what makes the theatre
				# immune to vanilla's own flavor_mch.17 (tag = MCH,
				# monthly_chance = 100), which can proclaim the Qing by itself
				# the month after MCH appears — sixteen game-years before we
				# get here — and re-tag the heir out from under a c:MCH call.
				save_scope_as = mr_qing

				# year they take China, which is the year this theatre lands.
				set_capital = location:dadu
				add_country_modifier = {
					modifier = MR_ulus_of_its_own
					years = 25
					mode = add
				}
				if = {
					limit = {
						country_rank_level < 4
					}
					set_country_rank_effect = {
						rank = country_rank:rank_empire
					}
				}
			}
		}
		# --- THE PROCLAMATION OF THE QING, AND IT MUST STAY LAST ---------
		# Vanilla's own Qing proclamation, copied verbatim from
		# flavor_MCH.txt:1024-1030 (flavor_mch.17, "Proclamation of the
		# Qing"). QNG IS NOT A TAG — it is a loc key (country_names:3034)
		# and a named colour (02_map.txt:2455); vanilla's Qing is MCH
		# wearing CHI's clothes. The flag is CHI's because vanilla's CHI
		# coat of arms IS the Qing one (pre_scripted_countries.txt:7776,
		# "CHI = { # China - Qing") and QNG has no coat of arms at all.
		# change_country_adjective is the load-bearing line: at rank_empire
		# the name composes from ADJ + RANK and the NAME key is never read
		# (country_name_construction.txt:117), so this renders "Qīng Empire".
		#
		# NOTHING MAY BE ADDED BELOW THIS BLOCK THAT NAMES c:MCH.
		scope:mr_qing ?= {
			form_country = formable_country:CHI_f
			hidden_effect = {
				change_country_flag = CHI
			}
			change_country_adjective = QNG_ADJ
			change_country_name = QNG
			change_country_color = map_QNG
		}
		# THE FLAG ONLY LANDS IF THE GROUND ACTUALLY WENT.
		#
		# MEASURED 1658, first live run: this family set its flag and moved
		# nothing. c:IRA had no country object, because a campaign in progress
		# cannot gain a tag added to setup/countries after the campaign was
		# created - the country database is minted once. The flag then sealed
		# the theatre for the rest of the campaign and Persia stayed Mongol
		# forever. A silent failure is survivable; one that marks itself done
		# is not.
		#
		# The test is the atom itself. If any claimant ground here is still
		# takeable the handover did not happen, so the effect retries next
		# month. If the atom never had any - the Khaghan did not own it - the
		# guard passes at once and the theatre is correctly recorded settled.
		if = {
			limit = {
				NOT = {
					OR = {
						scripted_geography:MR_geo_north_china = {
							any_location_in_scripted_geography = {
								mr_partition_takeable = yes
							}
						}
						scripted_geography:MR_geo_song_china = {
							any_location_in_scripted_geography = {
								mr_partition_takeable = yes
							}
						}
					}
				}
			}
			set_global_variable = mr_returned_china
		}
	}
}

# --- 16. BADAKHSHAN (1657) ------------------------------
# Mir Yar Beg founds the Yarid mirdom in the mid-1600s and his house
# holds the Oxus valley into the next century. BKH needs no
# registration: it is a live vanilla tag with its own identity block
# (east_asia.txt:3359) and its own start block, already seated at
# fayzabad inside badakhshan_area. Rides the same step as Bukhara:
# the Oxus valley goes when Transoxiana does.
mr_return_badakhshan = {
	if = {
		limit = {
			NOT = {
				has_global_variable = mr_returned_bkh
			}
		}
		scripted_geography:MR_geo_badakhshan = {
			every_location_in_scripted_geography = {
				limit = {
					mr_partition_takeable = yes
				}
				change_location_owner = c:BKH
				add_core = c:BKH
				change_integration_level = core
			}
		}
		if = {
			limit = {
				country_exists = c:BKH
			}
			c:BKH = {
				# The capital is set AFTER the sweep, because a country cannot be
				# seated in ground it does not own yet.
				set_capital = location:fayzabad

				# IDENTITY BY HAND — see the file header. A handover is not a
				# release, so the identity block's religion and culture are never
				# read and the heir would take both from the ground and from a
				# generated ruler.
				# DELIBERATE DEVIATION: BKH's own identity block declares mahayana
				# (east_asia.txt:3364), which is a statement about 1337 Badakhshan.
				# By 1694 the mirdom is Muslim — the lowlands Sunni, the Pamirs
				# Ismaili — and this situation exists to close the timeline back onto
				# the REAL map. One line to revert if that reading is rejected.
				# No dynasty: the Yarid mirs claimed Alexandrian, not Chinggisid,
				# descent, and vanilla ships no house for them.
				create_character = {
					estate = estate_type:nobles_estate
					first_name = Yarbeg
					age = 45
					culture = culture:tajik_culture
					religion = religion:sunni
					adm = { 40 70 }
					dip = { 40 70 }
					mil = { 40 70 }
					create_in_limbo = yes
					save_scope_as = mr_bkh_khan
				}
				set_new_ruler = scope:mr_bkh_khan
				change_religion = religion:sunni
				change_religion_for_ruler_and_family = {
					country = c:BKH
					religion = religion:sunni
				}
				change_culture = culture:tajik_culture

				# Twenty-five years of grace, the clause that makes the schedule
				# mean anything against a superpower carrying permanent rewards.
				add_country_modifier = {
					modifier = MR_ulus_of_its_own
					years = 25
					mode = add
				}
			}
		}
		# THE FLAG ONLY LANDS IF THE GROUND ACTUALLY WENT — the same guard
		# every theatre carries, so a silent failure retries instead of
		# sealing itself shut for the campaign.
		if = {
			limit = {
				NOT = {
					scripted_geography:MR_geo_badakhshan = {
						any_location_in_scripted_geography = {
							mr_partition_takeable = yes
						}
					}
				}
			}
			set_global_variable = mr_returned_bkh
		}
	}
}
